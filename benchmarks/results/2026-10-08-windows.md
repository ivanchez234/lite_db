# Замеры на Windows, 2026-10-08

Ноутбук автора: AMD Ryzen (Zen 4, Family 25 Model 117), 16 потоков, Windows 11 (10.0.26200), NTFS.
MSYS2 UCRT64, GCC 16.1.0, сборка Release. Клиент и сервер на одной машине, loopback.
Версия кода — та же, что в `2026-10-08-after.jsonl` (Linux).

```
python benchmarks/run.py --build build
python benchmarks/compare_size.py --build build
```

## Размер на диске против SQLite (100 000 строк, SQLite 3.53.1)

| Данные | Сырых данных | lite_db | SQLite | SQLite / lite_db |
|---|---:|---:|---:|---:|
| табличные строки | 1.6 МБ | 0.6 МБ | 2.0 МБ | 3.48× |
| случайные UUID | 4.2 МБ | 2.5 МБ | 4.6 МБ | 1.85× |
| скрытые повторы (base64) | 59.5 МБ | 10.4 МБ | 65.3 МБ | 6.30× |
| почти случайные (base64) | 28.2 МБ | 17.4 МБ | 30.1 МБ | 1.73× |

Совпадает с Linux (SQLite 3.45.1) до сотых.

Первый прогон на этой машине был сделан на отладочной сборке (`CMAKE_BUILD_TYPE=Debug`) и выброшен:
MPUT, конвейер и чтение с диска в ней были примерно вдвое медленнее. С тех пор `run.py`
печатает тип сборки и предупреждает, если это не Release.
